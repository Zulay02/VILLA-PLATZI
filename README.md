# Villa Platzi 🐷🐺

Granja interactiva hecha con JavaScript y `<canvas>`, del **Curso Gratis de Programación Básica de Platzi**.

## Cómo jugar

Abre `villa.html` en el navegador.

- 🐷 **Cerdo:** se mueve con las flechas ↑ ↓ ← →
- 🐺 **Lobo:** se mueve con las letras **W** (arriba), **S** (abajo), **A** (izquierda), **D** (derecha)

Las vacas y los pollos aparecen en lugares al azar cada vez que abres la página.

## Lo que practiqué

- Dibujar imágenes en un `<canvas>` con `drawImage`
- Objetos para guardar los datos de cada animal
- Números aleatorios con `Math.random()`
- Ciclos `for` para dibujar varios animales
- Eventos del teclado (`keydown`) y `switch` para mover a los personajes
