# Villa Platzi 🐷🐺

Granja interactiva hecha con JavaScript y `<canvas>`, del **Curso Gratis de Programación Básica de Platzi**.

## Juega en línea

👉 **https://zulay02.github.io/VILLA-PLATZI/**

## Los tres niveles

1. **El lobo persigue al cerdo** (dos jugadores): el cerdo huye con las flechas ↑ ↓ ← → y el lobo persigue con **W A S D**. Si el cerdo aguanta 30 segundos, gana el cerdo; si el lobo lo toca, gana el lobo.
2. **Rescata a los pollitos:** mueve el cerdo con las flechas y toca a los 6 pollitos antes de que el lobo, que te persigue solo y cada vez más rápido, te atrape.
3. **Junta el rebaño:** toca cada vaca para que siga al cerdo y llévalas todas al granero (abajo a la derecha) antes de 45 segundos.

## Lo que practiqué

- Dibujar imágenes en un `<canvas>` con `drawImage`
- Objetos para guardar los datos de cada animal
- Números aleatorios con `Math.random()`
- Ciclos `for` para dibujar varios animales
- Eventos del teclado (`keydown` y `keyup`) para mover a los personajes
- Un ciclo de juego con `requestAnimationFrame`
- Detectar cuando dos personajes se tocan (colisión de rectángulos)
